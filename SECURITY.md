# Security policy

Please report security problems **privately**, not in a public issue.

Examples:

- signing in to or taking over another player's account;
- server exploits, crashes you can trigger on purpose, or ways to bypass server checks;
- cheating vectors such as forged movement, duplicated items or currency;
- exposed personal data.

## How to report

Use GitHub's private reporting: open the **Security** tab of this repository and choose **Report a vulnerability** ([direct link](../../security/advisories/new)). Only the developer can see the report.

Please include the game version (from the window title bar), what you did, and what happened. Don't test against other players' accounts.

You'll get a reply once the report has been reviewed. Please give time for a fix to ship before sharing details publicly.
