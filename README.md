# ELDRYN Feedback

This is the public place to report bugs and suggest features for **ELDRYN**.

The game's source code is private. Issues filed here are read by the developer and linked to internal work. When a fix ships, the matching issue here is closed.

## Report a bug

[Open a bug report](../../issues/new?template=bug_report.yml)

Before you post:

1. Search the [existing issues](../../issues?q=is%3Aissue) in case it's already reported. If it is, add a 👍 or a comment with any new details instead of opening a duplicate.
2. Note your **game version**. It's shown in the game window's title bar, for example `ELDRYN 0.28.0-alpha.1`.

## Suggest a feature

[Open a feature request](../../issues/new?template=feature_request.yml) for a specific, concrete change.

For open-ended ideas, questions or general feedback, use [Discussions](../../discussions) instead.

## Security problems

**Do not open a public issue for security problems** such as account takeover, exploits, cheating vectors or exposed data. Report them privately instead. See [SECURITY.md](SECURITY.md).

## Please don't post

- passwords, login emails, session tokens or anything else that identifies your account;
- other players' personal information;
- step-by-step exploit instructions (report those privately).

## Labels

| Label | Meaning |
|---|---|
| `bug` | Something is broken |
| `feature` | A requested change or addition |
| `triage` | New, not yet reviewed |
| `needs-info` | Waiting for more details from the reporter |
| `confirmed` | Reproduced by the developer |
| `planned` | Accepted and scheduled |
| `fixed-next-release` | Fixed, ships in the next update |
| `duplicate` / `wontfix` | Closed without a change |
| `area:*` | Which part of the game it affects |
